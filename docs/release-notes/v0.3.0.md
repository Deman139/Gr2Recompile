## 🎯 Direct mouse aim (1:1)

The mouse now turns the camera **directly**: the emulated right stick is gone, and with it the dead
zone, the response curve and the speed cap. It is not 100% identical, but in practice it plays
almost exactly like a PC shooter.

- **Sensitivity:** about **1** is recommended (if you used 3-4 before, start from 1).
- **Fast turns (x1-x12, x6 by default):** while the mouse moves, the game's turn speed limit is
  raised so quick 90° / 180° flicks aren't held back. A controller keeps the game's own feel.
- **Invert Y axis.**
- ℹ️ By the game's design the camera turns at a different speed when walking and when sprinting:
  walking without sprinting can still feel a little odd. Sprinting and aiming behave like a true
  1:1 mouse.
- All of it in the launcher (*Controls*) **or live in the in-game menu** (*Controls* tab).

## 🔭 FOV slider

**80% to 150%** of the original field of view (100% = PS4). Set it in the launcher (*Game* tab) or
**change it live while playing** in the in-game menu: the view widens at once. Aiming zoom scales
in the same proportion.

## ⚙️ In-game menu: change settings without closing the game

Press **Insert** (or **R3 + L2**). Almost every launcher option is now in the menu and **most apply
at once**. The launcher and the game always show the same values.

| Tab | Option | Applies |
|---|---|---|
| 🎮 Controls *(new)* | Mouse sensitivity, fast turns, invert Y · FOV · vibration, stick dead zone, controller speaker · quick menu, startup tips | ⚡ Live |
| 🖼️ Image | Display mode, VSync, FSR 1, sharpening (RCAS) | ⚡ Live |
| | Upscaler FSR 3.1 / DLSS *(new, when the game started with one)* | ⚡ Live |
| | Frame generation Off / FSR 3.1 / DLSS *(new)* | ⚡ Live · 🔄 restart to turn it on from Off |
| | Texture sharpness (LOD bias) *(new)* | ⚡ Live |
| | Anisotropic filtering | 🔄 Restart |
| 🚀 Performance | Frame rate limit, frames queued, background shaders | ⚡ Live |
| | GPU readback options | 🔄 Restart |
| 📊 Overlay | FPS, frame time, upscaler, GPU, CPU, RAM, VRAM, size, corner, opacity | ⚡ Live |

- 🔄 **Apply and restart** now goes through the launcher: the game closes and starts again by itself
  with every new setting.
- 🚪 **Exit game** button in the menu.

**Shortcuts**

| Shortcut | What it does |
|---|---|
| **Insert** · **R3 + L2** | Open / close the in-game menu |
| **Hold Share / View / Select ~1 s** *(new)* | Quick menu: **Resume · Settings · Exit game**, from the controller alone (a short press still clicks the touchpad) |
| **Esc** · **Circle / B** | Close the menu |
| **L1 / R1** · **Q / E** | Switch tabs |
| **F12** | Screenshot |

## ⌨️ Shooter-style keyboard and the OWL

- New default keys: **Space** jump · **C** crouch · **R** reload/use · **Q** weapon · **1 / 3** L1 / R1 ·
  **Left Shift** sprint · **F** melee · **arrow keys** D-pad · mouse aims and fires. Keys you had
  already changed are kept.
- 🦉 **OWL drone on keyboard: hold Delete and move the mouse.** A short tip at startup now reminds
  you (it can be turned off: *Tips at startup*).

## 🚀 Performance

- The threads that feed the GPU and stream the levels run at a higher Windows priority, and on CPUs
  with **8 threads or fewer** the GPU command thread too: steadier frame pacing on weaker CPUs.
- New diagnostics for performance reports (GPU timings of the upscaler and frame generation).

## 🎯 Mouse directo (1:1)

Ahora el mouse gira la cámara **directamente**: se fue el stick derecho emulado, y con él la zona
muerta, la curva de respuesta y el tope de velocidad. No es 100% idéntico, pero en la práctica se
juega casi igual que un shooter de PC.

- **Sensibilidad:** se recomienda alrededor de **1** (si antes usabas 3-4, empezá desde 1).
- **Giros rápidos (x1-x12, x6 por defecto):** mientras movés el mouse se sube el límite de velocidad
  de giro del juego, para que los 90° / 180° rápidos no se frenen. Con mando se mantiene la
  sensación original.
- **Invertir eje Y.**
- ℹ️ Por diseño del juego, la cámara gira a distinta velocidad caminando que corriendo: caminar sin
  esprintar todavía puede sentirse un poco raro. Corriendo y apuntando se comporta como un mouse
  1:1 de verdad.
- Todo en el launcher (*Controles*) **o en vivo en el menú dentro del juego** (pestaña *Controls*).

## 🔭 Slider de FOV

**De 80% a 150%** del campo de visión original (100% = PS4). Se ajusta en el launcher (pestaña
*Juego*) o **en vivo mientras jugás** en el menú del juego: la vista se abre al instante. El zoom al
apuntar se escala en la misma proporción.

## ⌨️ Teclado estilo shooter y el OWL

- Teclas nuevas por defecto: **Espacio** saltar · **C** agacharse · **R** recargar/usar · **Q** arma ·
  **1 / 3** L1 / R1 · **Shift izquierdo** correr · **F** cuerpo a cuerpo · **flechas** cruceta ·
  el mouse apunta y dispara. Si ya habías cambiado teclas, se conservan.
- 🦉 **Dron OWL con teclado: mantené Suprimir y mové el mouse.** Ahora un consejo breve al empezar
  te lo recuerda (se puede apagar: *Consejos al iniciar*).

## 🚀 Rendimiento

- Los hilos que alimentan a la GPU y cargan los niveles corren con más prioridad en Windows, y en
  procesadores de **8 hilos o menos** también el hilo de comandos de la GPU: un ritmo de cuadros
  más parejo en CPUs más débiles.
- Diagnósticos nuevos para los reportes de rendimiento (tiempos de GPU del reescalador y de la
  generación de frames).
