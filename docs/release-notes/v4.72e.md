First public build of the Gravity Rush 2 PC recompilation.

**No game files are included.** You need your own PS4 dump of Gravity Rush 2 (CUSA04943) with update 01.11 and the system modules from your console.

## Install

1. Download **`GravityRush2-Setup-v4.72e.exe`** and run it (no administrator rights needed; don't install into Program Files).
   Prefer no installer? Download the zip and extract it anywhere outside Program Files.
2. Copy into the install folder:
   - `game\` — your dump: `eboot.bin`, `sce_module`, `sce_sys`, the `.psarc` files (update 01.11 merged in);
   - `sys_modules\` — `.sprx` modules from your PS4 (`libSceNgs2.sprx` required; `libSceJson2`, `libSceRtc`, `libSceFreeTypeOt`, `libSceFontFt`, `libSceFont` recommended);
   - `game\addcont\` — your DLC `.pkg` files, if any.
3. Start **Gravity Rush 2** and press Play.

**Requirements:** Windows 10/11, a Vulkan 1.3 GPU, 16 GB RAM.

## Highlights

- Launcher in English and Russian
- 60 FPS and up to 4K (Junmin Lee's patches, downloaded on first use), performance patches for crowded areas
- Keyboard and mouse remapping; Xbox, DualShock 4 and DualSense with gyro and light bar; Steam Input
- In-game port menu (F12 / R3 + L2), screenshots (F11), FSR 1, DLSS on RTX cards
- DLC support (shadPS4-compatible `addcont` layout), save backups before every launch

## Known issues

- Stutter while shaders compile on first launch and in new areas
- "Prepare cached shaders" can cause graphical artifacts (off by default)
- At 60 FPS the game slows down if the PC can't hold 60 FPS
- Photo mode can't save photos yet; PSN features are offline

Please report bugs with the logs from `user\logs\<date_time>\`.
