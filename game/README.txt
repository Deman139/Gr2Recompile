Папка для игры / Game folder
============================

RU: Скопируй сюда файлы своего дампа Gravity Rush 2 (CUSA04943, версия 01.11): eboot.bin,
sce_module, sce_sys и файлы .psarc. Можно и целой папкой (game\CUSA04943\eboot.bin).
Лаунчер подхватит их сам, если поле «Папка с игрой» пустое. Путь, вписанный в лаунчере,
важнее этой папки.

DLC: просто положи файлы .pkg с DLC (ключи-разблокировки по ~128 КБ) в папку игры. Лаунчер сам
распакует их в addcont\CUSA04943\<метка>\ внутри папки игры (так же их читает shadPS4: укажи
там папку DLC = <папка игры>\addcont) и удалит .pkg.

EN: Copy your Gravity Rush 2 dump here (CUSA04943, version 01.11): eboot.bin, sce_module,
sce_sys and the .psarc files, or the whole folder (game\CUSA04943\eboot.bin). The launcher
uses it when its game folder field is empty; a path set in the launcher takes precedence.

DLC: drop the DLC .pkg files (unlock keys, ~128 KiB each) into the game folder. The launcher
unpacks them into addcont\CUSA04943\<label>\ inside the game folder (shadPS4 reads the same
layout: set its DLC folder to <game folder>\addcont) and removes the .pkg files.
