Папка для системных модулей PS4 / PS4 system modules folder
===========================================================

RU: Скопируй сюда расшифрованные модули прошивки PS4 (.sprx) — те же файлы, что shadPS4
берёт из user\sys_modules. Обязателен libSceNgs2.sprx (звук игры); libSceJson2, libSceRtc,
libSceFreeTypeOt, libSceFontFt и libSceFont используются, если есть. Лаунчер подхватит их
сам, если поле «Системные модули» пустое. Путь, вписанный в лаунчере, важнее этой папки.

EN: Copy the decrypted PS4 firmware modules (.sprx) here: the files shadPS4 takes from
user\sys_modules. libSceNgs2.sprx is required (the game's audio); libSceJson2, libSceRtc,
libSceFreeTypeOt, libSceFontFt and libSceFont are used when present. The launcher uses this
folder when its modules field is empty; a path set in the launcher takes precedence.
